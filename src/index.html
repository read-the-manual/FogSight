点石子

三步看清磁盘 🌫️

  • 选位置：首页点一个磁盘，或者“扫描某个文件夹…”
  • 等它扫完：几十万个文件一般几秒钟，可以随时取消
  • 看石子：石子越大，占的空间越多。鼠标移上去，左下角显示名字、大小和占比

怎么操作

  • 左键点文件夹石子：进入这个文件夹
  • 右键点石子：在文件管理器里打开它
  • 后退 / 前进：鼠标侧键（靠下的后退，靠上的前进），或者左上角的箭头，跟 Windows 文件管理器一样。在最外层再后退，就回到选磁盘的首页
  • 这些按键都可以在“按键”里改

石子上的几种样子

  • 有颜色的石子：文件夹，里面的小石子是它装的东西
  • 白色石子：单个大文件
  • 虚线框“零散小文件”：小于 1 MB 的文件合在一起（太多了，单独画看不清）
  • 虚线框“其余 N 项”：太小、没有单独画出来的文件夹和文件

常见问题

  • 为什么扫出来比“已用空间”少一点？ 有些系统文件夹需要管理员权限才能读取，雾见会跳过它们，扫完后左下角会写跳过了几个。右键雾见 → 以管理员身份运行，就能扫到
  • 雾见会删我的文件吗？ 不会。雾见只读取文件大小，不会改动、移动或删除任何文件
