    点色块

    三步看清磁盘 🌫️

    • 选位置：首页点一个磁盘，或者“扫描某个文件夹…”
    • 等它扫完：几十万个文件一般几秒钟，可以随时取消
    • 看色块：色块越大，占的空间越多。鼠标移上去，左下角显示名字、大小和占比

    怎么操作

    • 左键点文件夹色块：进入这个文件夹
    • 右键点色块：在文件管理器里打开它
    • 后退 / 前进：鼠标侧键（靠下的后退，靠上的前进），或者左上角的箭头，跟 Windows 文件管理器一样。在最外层再后退，就回到选磁盘的首页
    • 这些按键都可以在“按键”里改

    色块上的几种样子

    • 带底色的色块：文件夹，里面的小色块是它装的东西
    • 白底的色块：单个大文件
    • 虚线框“零散小文件”：小于 1 MB 的文件合在一起（太多了，单独画看不清）
    • 虚线框“其余 N 项”：太小、没有单独画出来的文件夹和文件

    C 盘专清

    • 首页点“C 盘专清”，雾见会列出 C 盘上几个常见的“垃圾”位置和它们的大小
    • 每一项都写了删掉之后会怎样，默认一个都不勾，勾了、并在最后确认窗口点“确认清理”才会删
    • 删除是直接删，不进回收站。正在使用的文件会自动跳过
    • 下载文件夹、微信和 QQ 的聊天文件是你自己的东西，雾见只显示大小，不帮你删

    常见问题

    • 为什么扫出来比“已用空间”少一点？ 有些系统文件夹需要管理员权限才能读取，雾见会跳过它们，扫完后左下角会写跳过了几个。右键雾见 → 以管理员身份运行，就能扫到
    • 雾见会删我的文件吗？ 浏览色块的时候不会，只读取文件大小。只有在 C 盘专清里你亲手勾选、确认过的项目才会被删除
